# Athletic Head Injury Protocol — Field Blueprint

## Purpose

This tool supports licensed athletic trainers and authorized healthcare professionals with head-injury documentation, reassessment tracking, communication records, and return-to-participation workflow.

It does not independently diagnose concussion or clear an athlete for participation.

- Athlete ID
- Athlete name
- Date of birth
- School
- Sport
- Team
- Injury date
- Injury time
- Injury location

- Mechanism of injury
- Witnesses
- Immediate circumstances

- Weakness
- Numbness

- Midline cervical tenderness

- Emergency action taken
